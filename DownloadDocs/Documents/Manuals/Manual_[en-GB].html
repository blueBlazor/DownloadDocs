1. Introduction

This manual describes the operation of the Glue Distribution System used in corrugated cardboard production. The system supplies adhesive from four storage tanks to four application stations through two independent distribution lines.

Read this manual carefully before operating the machine. Only trained personnel may operate or maintain the equipment.

2. System Overview

Component Quantity Description
Glue Tanks 4 Storage tanks containing adhesive.
Distribution Lines 2 Main supply lines transporting glue to the stations.
Application Stations 4 Stations where glue is applied during production.

3. Glue Supply

Adhesive is stored inside one of the four glue tanks. Before production starts, verify that the selected tank contains enough glue for the planned production run.

The operator selects the required glue tank using the control system. Pumps transfer the adhesive from the selected tank into one of the two distribution lines.

The distribution line supplies glue continuously to the selected application stations.

Warning:
Never operate the pumps while a glue tank is empty. Running the pumps dry may damage the pumping system.

4. Operating Procedure

  1. Verify that the machine is powered on.
  2. Check the glue level in all tanks.
  3. Select the required glue tank.
  4. Select Distribution Line 1 or Line 2.
  5. Open the required application stations.
  6. Start the glue pump.
  7. Verify that glue pressure is stable.
  8. Start cardboard production.

5. Safety Instructions

  • Wear the required personal protective equipment (PPE).
  • Do not remove safety guards while the machine is running.
  • Disconnect electrical power before maintenance.
  • Release system pressure before disconnecting hoses.
  • Clean glue spills immediately to prevent slipping hazards.

6. Daily Maintenance

Task Frequency
Check glue level Daily
Inspect pumps Daily
Inspect hoses for leaks Daily
Clean filters Weekly
Inspect valves Weekly

7. Troubleshooting

Problem Possible Cause Solution
No glue at station Empty glue tank Refill or select another tank.
Low glue pressure Pump or filter restriction Inspect the pump and clean the filter.
No flow Closed valve Verify valve position.
Glue leakage Damaged hose Replace the damaged hose immediately.

8. Shutdown Procedure

  1. Stop cardboard production.
  2. Stop the glue pump.
  3. Close the glue valves.
  4. Clean the application stations.
  5. Inspect the machine for leaks.
